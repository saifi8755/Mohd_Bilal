# Bilal Saifi — Portfolio & Content Studio

A standalone Next.js project for GitHub and Vercel, with Supabase authentication, database and file storage.

Start with [DEPLOY.md](DEPLOY.md). Run `npm install`, then `npm run dev`. The public site runs with bundled content before configuration; admin and enquiries require Supabase.

Features: responsive red-black editorial design, six service pages, animated headings, accessible reduced motion, CV/resume uploads, social links, add/remove/reorder experience, drafts, preview, publish, history and inbox.

No credentials or node_modules are included. Images and fonts are included. Existing hosted database edits/uploads are not automatically migrated; this package contains the source defaults.

Admin URL: `https://yourdomain.com/admin1101` → authenticated dashboard at `/admin1101/dashboard`. Owner email: `saifi8755562245@gmail.com`. Create this owner in Supabase Authentication and set the password there.

Work pages include detailed responsibilities, editable process timelines, qualitative business benefits and deliverables. Workflow artwork is illustrative, not a real campaign sample. Add approved work samples in the Projects editor.
